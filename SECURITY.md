# Security Policy

## Supported versions

Security fixes are made to the latest code on the `main` branch. Older versions are not updated separately.

## Reporting a vulnerability

**Please don't report security problems in public issues, discussions or pull requests.** Report them privately, so they can be fixed before anyone else learns about them.

1. **Preferred: GitHub private vulnerability reporting.** Go to the [Security tab](https://github.com/KEX-03/taskflow/security) and click **Report a vulnerability**, or open the [report form](https://github.com/KEX-03/taskflow/security/advisories/new) directly. Only the maintainers can see your report.
2. **Alternative: email** [taskflow.kex@yahoo.com](mailto:taskflow.kex@yahoo.com) with the subject line `Security: <short description>`.

Please include:

- what the problem is and what an attacker could do with it
- steps to reproduce it (a request, a payload, or a small script)
- the affected file(s) or endpoint(s), if you know them
- whether it affects a deployed copy, local setup, or both

## What happens next

- You'll get a reply confirming the report was received. TaskFlow is maintained by volunteers, so please allow a few days.
- The maintainers will investigate, keep you updated, and work on a fix.
- Once the fix is released, you'll be credited in the release notes, unless you'd prefer to stay anonymous.

Thank you for helping keep TaskFlow and its users safe!
