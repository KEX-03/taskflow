**TaskFlow 1.0.0 is here!** 🎉 A clean, beginner-friendly full-stack task manager built with MongoDB, Express, React and Node, made for learning and first open-source contributions.

👉 **[Try the live demo](https://taskflow-plum-one.vercel.app)** (the first load can take up to a minute while the free server wakes up).

![TaskFlow dashboard](https://raw.githubusercontent.com/KEX-03/taskflow/v1.0.0/docs/images/dashboard.png)

## ✨ What TaskFlow does

- **Sign up and log in** with hashed passwords and JWT authentication
- **Dashboard** with task counts and your most recent tasks
- **Tasks**: create, edit and delete, with search and filters by priority and status
- **Profile**: update your name, bio and avatar, and change your password

## 🧑‍💻 Easy to run and learn from

- **One command to start everything:** `npm run install:all`, then `npm run dev` runs the API and the app together.
- **Up-to-date stack:** React 18, React Router 7, Tailwind CSS 4 and Vite on the frontend; Node.js, Express and MongoDB (Mongoose) on the backend. `npm audit` reports no known vulnerabilities.
- **Clear errors:** the server tells you exactly what's missing (an environment variable, MongoDB, a free port) instead of crashing.
- **Docs written for beginners:**
  - [How TaskFlow works](https://github.com/KEX-03/taskflow/blob/v1.0.0/docs/ARCHITECTURE.md): a five-minute tour of the code
  - [Deployment guide](https://github.com/KEX-03/taskflow/blob/v1.0.0/docs/DEPLOYMENT.md): put your own copy online for free with MongoDB Atlas, Render and Vercel
  - [Contributing guide](https://github.com/KEX-03/taskflow/blob/v1.0.0/CONTRIBUTING.md): from fork to pull request, step by step
